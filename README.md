# SafeMeds AI 💊

### Hear medicine details. Know when to verify.

SafeMeds AI is an accessibility-focused project designed to help visually impaired users and older adults read medicine labels more easily. The goal is to make medicine-label information more accessible through image scanning, text extraction, bilingual interaction, and voice output.

> **Current status:** Frontend prototype. Real OCR-based medicine label extraction and AI-powered question answering are planned for future development.

## ✨ Features

- **Medicine image upload:** Select or preview a medicine-label image.
- **Bilingual interface:** English and Hindi language options.
- **Voice accessibility:** Browser-based text-to-speech and microphone input where supported.
- **Interactive chat interface:** Explore the planned question-and-answer experience.
- **Medicine information panel:** Preview how extracted medicine details may be presented.
- **Responsive UI:** Designed for desktop and mobile screens.
- **Safety-first design:** Encourages users to verify uncertain medicine information with a qualified pharmacist or healthcare professional.

## ⚠️ Safety Disclaimer

This is an educational project prototype, not a medical device or a substitute for professional medical advice. The current demo may display sample information and does not independently verify medicine details. Always confirm medicine names, strength, expiry dates, and dosage instructions with the original packaging and a qualified healthcare professional.
